# PDR-0003: Current Template Workflow Authority

Status: Accepted
Date: 2026-10-07

## Context

The maintainer requested a detailed current-template synchronization before
separate domain work. Retained generic prompts and collaboration prose could
reintroduce old mandatory context/confirmation loops beside the current skills.

## Decision

Use AGENTS.md as the resident task router and COLLABORATION.md as the current
generic collaboration model. Current skills own bounded entry, handoff,
template comparison, consistency and retrospective methods. Retain legacy
prompt paths as compatibility pointers; preserve their earlier text in Git
history. ChatGPT.md and CODEX.md retain supplemental domain/execution safeguards,
but historical generic procedures are not independently executable authority.
This replaces the old blanket prompt/full-context routing only; it does not
supersede accepted architecture, scope, private-source or host-operation rules.

## Rationale

One current method avoids contradictory lifecycle, excessive reconstruction and
repeated confirmation while keeping the concrete project independent.

## Consequences

- Preserve recognized control words, private-upload/host-operation gates,
  bounded commit-and-normal-push authority and separate action approvals.
- Keep existing required domain checks, fixture/material locations, versions,
  licensing, initialization provenance and real-system validation limitations.
- Read supplemental policies when relevant; do not load a complete former
  workflow merely to begin a bounded task. No initialization is rerun.

## Alternatives considered

Keeping parallel executable prompt methods retains contradictory instructions.
Deleting all legacy files would obscure local safeguards and existing links.
Copying source-template domain/state files would erase accepted project intent.

## Follow-up

Validate current skills, router/model coverage, compatibility links and preserved
domain boundaries independently. Source/scenario review does not prove future
model compliance, live visual/host behavior or publication readiness.
