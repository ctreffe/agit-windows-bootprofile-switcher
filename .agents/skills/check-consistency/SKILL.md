# Check Consistency

Define the internal consistency scope and compare the repository's current
artifacts with its stated intent, roadmap, accepted decisions and validation
contracts. Identify contradictions, stale claims, missing links and mismatched
implementation or documentation with exact evidence.

For each material finding, explain impact and develop proportionate solution
options or a recommendation. Do not compare with a source template and do not
implement a solution unless the user separately requests the change.
